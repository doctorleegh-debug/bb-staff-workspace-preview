# 뷰티블라썸 직원 업무 초안 검수

[화면 열기](https://doctorleegh-debug.github.io/bb-staff-workspace-preview/)

직원 업무 화면의 구성·글씨 크기·버튼·팀 필터·등록 흐름을 검수하는 공개 초안입니다. 사용자 요청으로 직원 표시 이름을 유지했습니다. **일정·식대·OT·지각·메모는 모두 새로 만든 예시이며 실제 개인 기록이 아닙니다.** 실제 Google Sheets 자료·주소·원본 XLSX는 포함하지 않습니다.

## 화면

- 팀 일정과 직원별 근무표
- 현재 명부 45명 개별 테스트 로그인(본인 이름 + 1111, 동명이인은 팀 선택). 직원 화면: 내 근무표·내 식대·내 OT, 식사·휴식·외출·외근 시작/종료 / 관리자 화면: 실시간 상태와 월간 통계
- 날짜별 영수증 사진 등록·달력·사진 뷰어 / 관리자 직원별 조회·ZIP 다운로드·보관 기간 설정
- 식대와 OT·지각 조회/등록 · 직원별 오른쪽 슬라이드 캘린더
- 37개 예시 탭 보기와 공통 월·직원 검색·팀 드롭다운

모바일에서는 식대·OT·기록 표가 세로 카드로 표시되고 근무표는 직원별 월간 달력으로 펼쳐집니다. 개인 달력의 날짜를 누르면 정확한 금액·시간·메모를 확인할 수 있습니다. 병원 제공 로고는 둥근 사각형으로 표시합니다.

본문16px·메뉴18px, 주요 버튼48px 이상, 흰색 카드·파란색 포인트·옅은 회색 배경이며 상단에서 다크모드로 전환할 수 있습니다. 상태 버튼은 정사각형 카드로, 영수증 달력은 등록 여부·사진·금액을 표시합니다. 입력한 테스트 기록은 해당 브라우저에 저장되며 다른 검수자와 동기화되지 않습니다. 화면 체험용 테스트 로그인이 제공되며 서버 인증과 운영 권한은 구현 전입니다. 영수증 사진은 이 브라우저 IndexedDB에 저장됩니다. 사진 보관 기간은 기본 30일이며 설정만 저장하고 실제 자동삭제는 서버 연결 후 적용합니다. 실제 업무 자료를 이 공개 초안에 입력하지 마세요.

## 실행

Node.js 설치 후 npm ci, npm run build, npm start. 로컬 주소 http://127.0.0.1:4174. GitHub Pages는 main 브랜치의 docs 폴더를 사용합니다. 변경 뒤 npm run build 결과도 함께 커밋해야 합니다.

## 사용설명서와 피드백

직원·관리자 화면 상단에 사용설명서와 피드백·요청사항 메모장이 있습니다. 저장한 메모는 같은 브라우저의 관리자 **메모취합**에 표시됩니다. 다른 기기의 의견은 직원의 메모 파일 내려받기 → 관리자 메모 파일 가져오기로 취합합니다. 작성자·화면·내용별 검색과 조회한 메모 다운로드를 지원합니다. 검수 메모장은 최종 배포 때 제거합니다.

## 검수할 항목

1. 메뉴와 글자·버튼 크기
2. 팀/월을 바꿨을 때 화면 내용
3. 식사 시작·종료와 새로고침 복구
4. 일정·식대·OT 등록 흐름
5. 모바일 세로 카드와 가로 스크롤 없는 7열 달력

소스: src/clinic-app.js, src/clinic.css, src/meal-timer.js, src/daily-detail.js. 이 저장소는 화면 검수용이며 운영 서버·원본 시트 동기화·서버 인증을 포함하지 않습니다.
