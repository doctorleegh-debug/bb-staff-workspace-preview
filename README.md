# 뷰티블라썸 직원 업무 초안 검수

[화면 열기](https://doctorleegh-debug.github.io/bb-staff-workspace-preview/)

직원 업무 화면의 구성·글씨 크기·버튼·팀 필터·등록 흐름을 검수하는 공개 초안입니다. 사용자 요청으로 직원 표시 이름을 유지했습니다. **일정·식대·OT·지각·메모는 모두 새로 만든 예시이며 실제 개인 기록이 아닙니다.** 실제 Google Sheets 자료·주소·원본 XLSX는 포함하지 않습니다.

## 화면

- 팀 일정과 직원별 근무표
- 식사중 → 60분 타이머 → 식사종료 및 실제 소요 시간
- 식대와 OT·지각 조회/등록
- 37개 예시 탭 보기와 공통 월·팀·직원 필터

본문16px·메뉴18px, 버튼48px 이상, 녹회색 배경입니다. 입력한 테스트 기록은 해당 브라우저에 저장되며 다른 검수자와 동기화되지 않습니다. 로그인과 운영 권한은 구현 전입니다. 실제 업무 자료를 이 공개 초안에 입력하지 마세요.

## 실행

Node.js 설치 후 npm ci, npm run build, npm start. 로컬 주소 http://127.0.0.1:4174. GitHub Pages는 main 브랜치의 docs 폴더를 사용합니다. 변경 뒤 npm run build 결과도 함께 커밋해야 합니다.

## 검수할 항목

1. 메뉴와 글자·버튼 크기
2. 팀/월을 바꿨을 때 화면 내용
3. 식사 시작·종료와 새로고침 복구
4. 일정·식대·OT 등록 흐름
5. 모바일 화면과 표 스크롤

소스: src/clinic-app.js, src/clinic.css, src/meal-timer.js. 이 저장소는 화면 검수용이며 운영 서버·원본 시트 동기화·로그인을 포함하지 않습니다.
